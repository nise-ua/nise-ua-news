# Digest prompts

Canonical editable files for digest commentary and assembly:

- `prompt.md` — sarcastic Phase A commentary
- `prompt_deep.md` — architect Phase A commentary
- `assembly_prompt.md` — Phase B assembly
- `config.md` — hashtag, border, suffix

Local runs and Docker (`./prompts:/app/prompts`) both load this directory.
Do not keep a second copy at the git repository root.
